# 情境版题目与动作

用户希望多数题目直接来自登塔体验，又明确要求不要给普通题贴上游戏名词。选择的标准是：场景应当为具体的观察或处理过程提供信息，A/B两侧都应合理，而且不需要玩家掌握强卡、流派或生存策略。

## 编辑原则
- 保留四个MBTI风格维度，测的是倾向的趣味线索，并无心理测量验证。
- 尖塔题关注如何读地图、理解遗物、回看战斗、处理待定奖励、安排补给，以及与实际存在的NPC交流。题干补足必要信息。
- 谈游戏时不决定最优策略；问处理过程、关注点和决定时机。游戏经验仍可能影响回答，不宣称完全消除了混淆。
- E/I和T/F有些内容在日常关系里更自然，不虚构多人队伍或背叛救援任务。保留日常题作其他角度的观察，并不声称它们验证了情境题的测量效度。
- 题目是原创假设，包括NPC对话的延伸，不是原作实际剧情选项。
- 采用A/B五档：很像A、偏向A、两者皆可、偏向B、很像B。每题的axis/direction/编写理由见questions.js。

## 具体删改
- 删除“残血是否打精英”思路：主要受风险、牌组和水平影响。
- #6删去“有意思的变化”，改为整体路线关系与具体节点信息。
- #20改成暂停前是否完成选牌，避免重复#8的路线定案问题。
- #24改为战后的复盘顺序，避免把准备是否充分计为J/P。
- #36从开局定流派改为自由周末安排，避免将正确策略等同于P。
- 不以比例为编辑目标。最终30题含19道尖塔题，50题含27道，其余为日常锚点。

## 动作说明
所有16种结果都有自己的2.8秒动作，使用静态角色图片和独立SVG特效。包括铁甲战士焰刃、静默猎手双匕首与毒雾、机器人充能球、观者姿态转换、时间吞噬者时钟、收藏家火炬、商人抛币、涅奥祝福、甜圈强化、八体护盾、守护者防御模式、地精首领召集、牧师疗愈、兰伟德药水、换脸商面具与邪教徒仪式。

进入档案后待图片加载再播放；按钮可以重播。没有循环播放和音频；减少动态效果偏好关闭演出。下载的PNG是静态身份卡。动作是同人演绎，不是假装提取了原作的骨骼或逐帧动画。

## 版本3：逻辑与可读性修订

用户要求主动修正明显不合逻辑的题目，并发来第10、20、24题手机截图，指出题干和选项难懂。修订30题的可见文字，保留原axis/direction与题序；营火题第16题按用户后续明确要求完整保留，题干与A/B逐字不变。题目分布仍为19/30、27/50。

- 第12题：去掉“用途或预算”的双重问题，A/B只比较是否先定用途。
- 第15题：从是否接受结论改为是否采用安排，避免把事实是否成立与照顾人的需要对立。
- 第21题：固定人数与熟悉程度，只比较互动节奏，不把深聊、熟人等同于内向。
- 第34题：改问外形与动作引起的关注，减少与第10题的同义重复。
- 第38题：说明已了解充能球基础，避免把新手知识需求计为S。
- 第43题：去掉“目标明确”，区分个人价值与一致标准，减少JP因素。
- 第44题：明确为局后纸上构思，去掉未来奖励和构筑策略的干扰。
- 第49题：去掉“固定留时间”，只比较独处与交流的偏好。
- 第7题：给定收费清楚、态度友好，避免将关怀与诚实设为对立。
- 第10题：用“先回想每回合／先猜出招套路”替代归纳与模式检验术语。
- 第20题：明确暂停游戏，直接用“先休息／先选牌”表达区别。
- 第24题：明确回忆刚才的战斗，补充用药水、出牌的例子，去掉核对问题等抽象说法。
- 其余修改缩短句子，把抽象措辞改成可想象的行为。中间选项改为“两者接近”，不是“两个选项我都能做到”。

四轴定义参考 [Myers & Briggs Foundation 的偏好说明](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences)：它们描述偏好，不是能力、善恶或是否理性。此来源只用于编辑边界，不代表本站题目获得测量验证或授权认证。

评分纠正：取消“第一道非中立答案打破平分”和“全部中立默认为INFP”。平分保留X、列出相容类型；浏览候选图鉴不改变个人结果。增加稀疏数组校验，防止缺失答案被误认作完整作答。旧v1/v2答案保留，不用于v3计分。
