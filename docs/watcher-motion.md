# 观者短动作优化

目标：让观者的平静与愤怒姿态在短演出中可辨，出招与特效同步。

选择两层 SVG 加现有原画的方案。单独加亮光圈无法改善动作节奏；重做逐帧角色素材会扩大这次修改的范围。

2.8 秒内依次呈现：蓝色莲息与微光、后倾蓄势、红色气场与禅杖弧光、余烬消散、回到原位。光晕与气场在人物后方，莲花、杖影与余烬在前方。静态原画配原创动效，不作为游戏原版动作展示。

实施范围：`dist/motions.js` 的观者图形与前后层输出，`dist/motions.css` 的观者关键帧与层级。保留其他角色、时长、计分及重播接口。

验证：现有单元与 DOM 检查；共享浏览器可用时，捕捉桌面及手机的五个动作阶段，检查重播、结束静止、减少动态效果、页面溢出及控制台错误。

本次结果：8项单元测试及完整DOM流程检查通过；观者的两层SVG可解析，其他15个角色输出逐一与旧版比对相同。共享浏览器锁仍被占用，实际视觉播放尚未验收；未打开标签页、启动预览服务或中断其他任务。后续视觉检查脚本保存在本地 artifacts/watcher-qa.mjs。
