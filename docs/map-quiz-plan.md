# 地图式答题

按用户给的聊天截图实现：答题界面是一张向上爬升的地图，每个节点对应一题；回答后先展示沿路线移动，再弹出下一题。

采用固定路线，30或50个题目节点与一个终点。完整地图可以滚动查看，已回答节点可回访，未到达的节点不能跳题。选择固定路线是为了保留原有题量、顺序与计分，不让路线选择改变测量内容。题库仍为v3，第16题营火的题干与选项保持原文。

视觉为羊皮纸地图、暗蓝外框、墨色未走路径与金色已走路径；节点用营火、战斗、商店、事件等图标表达场景。进入节点后弹出原有高对比题卡。手机采用居中的可滚动题卡，卡片关闭后能看完整地图。

实现分工：journey-map.js/css负责地图图形、节点状态、定位和900ms路程动画；app.js负责题卡、答题、存储、前进锁、取消和结果跳转；quiz-map.css负责页面及弹出题卡。已保存的v3答案继续有效，不重新开始。

流程：选择答案→短暂停留确认→锁定前进→保存下一节点→关闭题卡→沿路线移动→打开下一题。连续点击不会跨过题目。保留手动前进选项，手动与自动都播放同一段路程；减少动态效果时立即到达。

离开测试、刷新、回访旧题、最后一题和取消动画都要明确处理。刷新时从已经保存的节点继续，旧答案保持。题卡支持键盘1–5、Enter及Escape回地图，地图按钮可键盘访问。

验收：30/50题完成与原计分一致，上一题/回访/刷新保存，重复输入不跳题，最后一题到终点，路由离开取消动画，减少动态效果；桌面/手机实际浏览器检查题卡、地图、前进画面和页面溢出。

验证结果：17项单元测试通过；实际模块DOM流程通过，包含30/50题、旧进度隔离、持平结果与全部角色图鉴。共享Chrome后台任务页完成30/50题，验证900ms正常动画、快速重复输入、回看已答节点、移动中刷新/离开、减少动态效果和最终登顶。1440×1080、390×844、320×568检查无横向溢出；手机长题卡可内部滚动，底部操作可达。第16题题干逐字核对，未改。

浏览器检查通过CDP请求后台页面的合成帧，未激活标签或桌面窗口；结束后关闭任务标签。记录位于本地忽略目录 `artifacts/map-browser-checks.json`，截图为 `artifacts/map-*.png`。地图专用检查脚本为 `scripts/map-browser-qa.mjs`。
