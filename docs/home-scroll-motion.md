# 首页滚动动效

首页首屏随滚动降低插画亮度并略微移动背景；角色区的蓝金雾光逐渐显现。小标题、四张角色卡与三段说明进入视口时依次淡入。返回上方时背景恢复，正文保持可见。

选择局部景深与透明度变化，保持原有布局和阅读节奏。舍弃整屏切换、滚动劫持和大幅镜头运动，避免影响开始测试及手机阅读。

实现：独立的 home-motion.js / home-motion.css；IntersectionObserver 触发一次性内容揭示，passive 滚动监听合并到 requestAnimationFrame 更新背景。路由离开和切换题量时释放监听。无浏览器支持或启用减少动态效果时显示静态内容；键盘聚焦可立即揭示内容。

验证：滚动往返、一次性揭示、键盘焦点、系统动态偏好改变、路由清理；已有答题流程回归。共享浏览器可用时检查桌面及手机的实际布局与滚动帧。

执行结果：11项单元测试通过，覆盖背景往返、同帧合并、取消待执行帧、释放监听、焦点揭示和动态偏好切换。30/50题完整DOM流程、人物结果与重播回归通过；新样式表可解析。共享浏览器锁仍在占用，实际滚动与手机渲染尚未验收。
