# 一代地图图标、翻牌与随机岔路

2026-11-07，按用户连续补充的要求完成同一轮更新：使用塔1图标；普通怪表示游戏情境，问号表示日常问题；保留商店；到达后画圈；翻开卡牌展示题目；每次新旅程随机生成地图，其他岔路在距塔顶2–8层处以叉号结束。

## 节点含义

图标是体验上的分类，不参与计分，也不改变题序。每道题仍然等权，题库版本保持3；原有答案可以继续使用。

- 普通怪：游戏相关的情境题。
- 问号：与游戏无关的日常题。以下特殊主题继续使用各自的专属图标。
- 精英：需要停下来考虑影响、价值或安排的重点题，编号15、19、24、35、40、41、43。它们没有额外分数，也没有标准答案。
- 营火：休息、恢复精力、暂缓决定的题，编号13、16、20、29、49。第16题原文逐字保留；题卡增加暖色和一句简短提示，不强制等待。
- 商店：资源取舍，编号12「留给商店的金币」和30「删牌之前」。第1题虽然有商人，但关注交易结束后的聊天习惯，使用普通怪图标。

没有增加商店购买、生命值、额外题目或真实失败惩罚；问卷仍然完整覆盖30/50题。

## 图形来源

普通怪、精英、问号、营火、钱袋和终点图标，采用[一代图鉴的地图图标素材](https://github.com/xxxawenxxx/GuideSlayTheSpire/tree/master/app/src/main/res/drawable)，并对照[一代地图图例](https://slaythespire.wiki.gg/wiki/Map_Locations)及[原作地图截图](https://interfaceingame.com/screenshots/slay-the-spire-map/)。不采用二代、模组或另一组现代线条图标。

原文件是100×100像素的图标截图，保存时未改像素。网页通过SVG滤镜把浅色截图背景转换成透明度，再以界面墨色显示原轮廓；地图、图例和翻牌题面共用同一实现，不再依赖背景混合。记录见 `dist/assets/map/provenance.json`。游戏图形版权归Mega Crit及相应权利人。墨圈和叉号用SVG复现原作的粗细不均、留有笔锋的墨迹感觉，并非从游戏导出的贴图。

## 到达与翻牌

小人物沿路线前进900ms。抵达时在目标图标上画出墨圈，480ms内完成笔画并稍作停留。墨圈完成后打开地点背景，镜头轻推520ms，随后题卡用560ms从卡背翻到题面。地图上的墨圈记录到达过的节点。题卡顶栏显示地点和地图按钮，商人房间还可下拉摊布。

首页提前准备起步或续答地点，答题时提前请求下一处场景并解码。18张实景各有一张随应用提供的小图，大图晚到时先呈现相同构图，再淡入清晰画面。翻牌时间由动画控制。系统开启减少动态效果时直接显示题面。

翻牌期间题面设为inert，并拦截数字键、Enter和答题事件。结束后恢复交互并聚焦题干。关闭或离开会取消监听、定时器和后续聚焦。系统减少动态效果时立即显示题面；动画事件缺失时有超时释放，避免锁住答题。

## 随机地图

每段新旅程生成独立的`mapSeed`，随v3答案保存在当前浏览器。旧进度第一次打开时补上种子，不清除答案；刷新、回看或续答保留本次地图。

主线仍逐题向上，到达终点。旁路从主线分出，使用同样图标和虚线，最终以手绘叉号结束，终点位于距塔顶2–8层处。旁路用于营造地图叙事，不因某个答案判定死亡，也不改变你的题目。

按后续参考截图，生成主线与3条岔路，最多4条路线并行。主线随机穿行四个横向区域，包含左右两侧；节点有轻微位置偏移。岔路在层间交织，间隔几层共用一个节点，随后重新分开。共用节点和路线只绘制一次，死亡叉号不与其他节点合并。

每条路线每层一个节点；主支线的图标、墨色、透明度和虚线样式一致。地图普通图标从桌面64px/手机58px缩到32px/29px，墨圈、终点及叉号同步缩小；点击范围仍为桌面55px、手机48px。图例与题面小图标保持便于阅读的尺寸。路线与人物移动共用同一组斜向贝塞尔曲线，保证交叉处也沿实际路线前进。

## 文字避让

当前楼层、类型和题目名放在地图上方的固定信息栏，抵达或回访节点时同步更新。路线区域不再放题目标题、章节文字或人物头顶文字。起点说明位于最底层节点下方，终点说明位于终点图标及人物上方的独立留白中；无需给文字盖一块底色遮住路线。

## 验证

26项单元测试通过，覆盖每层节点密度、四路上限、主线横跨左右、随机交汇、岔路边界及终点范围。真实浏览器检查30/50题完整流程、翻牌、取消、减少动态效果及刷新续答；1440/390/320px截图和尺寸检查确认主支线图标等大且缩小一半、触控范围充足、题目标题在路线区域之外且无横向溢出。六种图标的四角透明度均为0，保留可见的原图墨迹。验证脚本为 `scripts/map-browser-qa.mjs`、`scripts/map-density-qa.mjs`，报告在本地artifacts目录。
