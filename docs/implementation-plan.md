# 尖塔人格档案

Goal: 完成可使用的中文 MBTI 风格网站，支持 30 / 50 题，以《杀戮尖塔》一代角色展示 16 型结果。

Architecture: 无构建依赖的 HTML / CSS / ES modules。问卷和计分独立于界面；答案仅保存于浏览器。Sites 私有托管。用户明确授权全程自主决策。

## 设计与取舍
- 采用深海蓝、旧金色、羊皮纸与幻想插画；不采用通用白底表单或霓虹科技风。
- 日常性格陈述，五点同意度，四轴交错；30 题为前 30 题，50 题增加 20 题。
- 正反向计分，每轴独立归一化。版本3起，零分轴保留为X并显示相容类型，不作暂定字母分配；不声称官方 MBTI 或心理诊断。
- 首页选择题量、逐题作答、返回修改、保存进度、结果四轴、故事依据、成长提示、16 型图鉴、下载结果卡。
- 故事事实与同人诠释分开，各角色附资料链接。

## 实施步骤
1. tests/scoring.test.mjs 覆盖两种题量、所有 16 型、反向题、空答案、平分和不合法输入；先确认缺少实现时报错。
2. dist/questions.js 提供 50 个原创条目及维度、方向；dist/scoring.js 实现纯函数。
3. dist/characters.js 与 assets/characters/ 存角色内容及本地图片；docs/lore-sources.md 存来源。
4. dist/index.html、styles.css、app.js 实现页面、持久化、分享卡与无障碍交互。
5. 运行 node --test；共享 Chrome CDP 6112 后台标签验证 30 / 50 完整流程、改答、刷新、手机尺寸、图鉴和下载；保存截图并关闭任务标签。
6. 使用 Sites source helper 推送、打包与私有发布，核验部署终态。
